# Open beslissingen: upgrade PEP VZW 17.0 → 20.0

- [ ] **Coördinator:** Bevestig je dat productie de branch `17.0` van clm-open draait en niet `enterprise`? Op `enterprise` (2 commits, 2022) staan alleen manifesten met versie 14.0 en 15.0: Odoo 17.0 weigert ze te laden ("Invalid version '15.0.0.0.0'"). `17.0` bevat de migratie naar v17 (juli 2024) en 4 fixes van 2025-2026. De upgradebranch vertrekt daarom van `17.0` (`481be07`). De checkout op de server (remote, branch, commit) is nog niet gelezen.
      Advies: lees `git -C <addons-map> log -1` en `git status` in de Odoo-container van PEP op portainer.odoo.digitalevzw.be, en zet de productiebranch van omgeving 502 op `17.0`.
- [ ] **Coördinator:** Zet je de beveiligingsfix `82484a8` nu al op productie (17.0)? Elke portaalgebruiker kan vandaag via JSON-RPC elk contact van het bedrijf wijzigen: het maatwerk geeft portaal schrijfrecht op contacten, en de standaardregel beperkt alleen het lezen. Bewezen op een 17.0-kopie: lezen geweigerd, schrijven gelukt. De fix voegt een schrijfregel toe (alleen de eigen organisatie) met 2 tests, groen op 17.0.
      Advies: cherry-pick `d7a7ced` en `82484a8` op `17.0` en update `clm_contact_manager` op productie deze week.
- [ ] **Coördinator:** Kan de agent de databank van productie lezen (dump, SQL of SSH met de agentsleutel)? Omgeving 502 heeft vandaag geen dump-, SQL-, RPC- of shell-toegang. Zonder databank blijven open: de lijst van geïnstalleerde modules, de Studio-aanpassingen van het formulier op /my/account, `upgrade/before.json` (de basis van fase 8) en het zaaddata-script voor de 20.0-kopie.
      Advies: geef de agent een dump van `pepvzwent` (of SQL-toegang alleen-lezen) via de omgevingsinstellingen; dat is de snelste weg.
- [ ] **Functioneel consultant:** Moet een lid na het aanmelden nog altijd op "Mijn account" (/my/account) landen in plaats van op het portaaloverzicht (/my)? Dat staat vast in de code sinds 2023. Het botst met de standaardtest van Odoo (`portal`), die /my verwacht: zo raakt de poort van fase 4 (alle tests groen) niet gehaald.
      Advies: maak er een instelling van (systeemparameter met de landingspagina), zet ze voor PEP op /my/account via een migratiescript, zodat het gedrag voor de leden gelijk blijft en de standaardtest groen is.

      Advies: beslis pas na de lijst van geïnstalleerde modules van productie (item 3); wat niet geïnstalleerd is, valt buiten de upgrade.
- [ ] **Klant:** Ga je akkoord met deze keuze per module: `clm_contact_manager` porten naar 20.0, `clm_contact_manager_website_fix` porten (en in fase 5 samenvoegen met `clm_contact_manager`)?       Advies: laat agentd `mode=upgrade` zonder `dump` toelaten (verse 20.0-databank plus `seed`), zoals de beschrijving belooft; de agent bouwt de kopie dan in de volgende run.
